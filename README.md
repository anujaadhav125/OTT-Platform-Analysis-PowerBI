# OTT Platform Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard for analyzing content across three popular OTT platforms: **Netflix, Amazon Prime Video, and Disney+ Hotstar**.

The dashboard provides insights into movies, TV shows, genres, release-year trends, country-wise content distribution, and other platform-specific information through interactive visualizations.

## 🎯 Project Objectives

- Analyze content distribution across OTT platforms.
- Compare movies and TV shows.
- Understand genre-wise content distribution.
- Analyze titles released across different years.
- Explore country-wise content availability.
- Present platform-specific information through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and aggregations, where required
- **CSV Datasets** – Data sources for OTT platforms

## 📊 Dashboard Features

### 1. Netflix
- Total Titles
- Average IMDb Score
- Average Runtime
- Titles by Genre
- Titles Released by Year
- IMDb Score Distribution
- Titles by Language
- About Netflix Originals

### 2. Amazon Prime Video
- Total Titles
- Movies and TV Shows count
- Titles by Genre
- Titles Released by Year
- Movies vs. TV Shows distribution
- Top 10 Countries by Content
- About Amazon Prime Video

### 3. Disney+ Hotstar
- Total Titles
- Movies and TV Shows count
- Titles by Genre
- Titles Released by Year
- Movies vs. TV Shows distribution
- About Disney+ Hotstar

## 🧹 Data Preparation

Data preparation was performed using Power Query. The process included:

- Checking and handling duplicate records.
- Reviewing missing and blank values.
- Assigning appropriate data types to columns.
- Preparing datasets for visualization.
- Using aggregation to calculate title counts and other metrics.

## 📈 Key Insights

The dashboard can help users explore:

- Which genres have more content.
- How content releases vary by year.
- The distribution of movies and TV shows.
- Country-wise content availability.
- IMDb ratings and runtime trends for Netflix Originals.

*Actual findings depend on the data and filters selected in the dashboard.*
